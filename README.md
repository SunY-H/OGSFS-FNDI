# OGSFS-FNDI

本项目提供以下论文的 MATLAB 代码：

**基于模糊邻域判别指数的在线流组特征选择**

徐久成，孙元豪，韩子钦。
《计算机工程与设计》，2024，45(3)：806–813。

[论文链接](https://doi.org/10.16208/j.issn1000-7024.2024.03.023)

## 简介

本文提出一种基于模糊邻域判别指数的在线流组特征选择方法，利用判别指数刻画模糊邻域粒的判别信息，并通过组内和组间特征选择保留具有较强近似能力的特征、剔除冗余特征。

实验入口为 `main(Data, G, alpha)`，核心算法为 `OSGFS_FNDI.m`。目录中保留了原始 MATLAB 文件及 Breast、Heart、MLL 数据文件。

如果本代码对您的研究有所帮助，请引用上述论文。
